# Predictive Analytics Using Historical Data

## Project Overview
This project focuses on predicting future sales trends using historical data from the Sample Superstore dataset. A Machine Learning model is developed using Python and Linear Regression to forecast future sales.

## Objectives
- Analyze historical sales data.
- Clean and preprocess the dataset.
- Identify monthly sales trends.
- Build a predictive model using Linear Regression.
- Evaluate model performance using accuracy metrics.
- Forecast future sales for the next six months.

## Dataset
**Dataset Name:** Sample - Superstore.csv

The dataset contains historical retail sales information, including:
- Order Date
- Sales
- Profit
- Quantity
- Category
- Region
- Customer Information

- Python

- Seaborn
- Scikit-learn

## Project Workflow
1. Dataset Loading

5. Linear Regression Model Development
6. Model Training and Testing
7. Model Evaluation
8. Future Sales Forecasting
9. Data Visualization

## Model Evaluation
The model performance is evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Expected Outcomes
- Understand historical sales patterns.
- Predict future sales trends.
- Evaluate predictive model performance.
- Support data-driven business decisions.

## Conclusion
This project demonstrates how predictive analytics and machine learning techniques can be used to analyze historical sales data and forecast future business trends. Linear Regression helps identify sales patterns and supports better business planning and decision-making.
